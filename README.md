# Daily Opus

The day's sky, Church calendar, tarot, alchemy, Kabbalah and Enochian, with a study program.

Live at https://sacenteno99.github.io/daily-opus/ (installable as an app; also works as a Lively Wallpaper).

This site is generated from the Daily Opus artifact. Open pages check `version.json` every 20 minutes and reload when a new build is published.
